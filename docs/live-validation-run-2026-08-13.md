### JSON 输出缺失的后续修复

两次成功创建都在 freee 已显示新申请后、CLI 输出 JSON 前停止。原实现会离开刚生成的详情页，再从列表重新搜索并打开同一详情。修复后会先保存提交后当前详情页，再回列表确认只新增了一条申请，并直接组合两份只读证据返回结果，不再重复打开详情。

自动化回归测试确认成功路径只点击一次、读取一次当前详情、不会重新打开详情，并仍会在提交后详情缺失时返回结果未知。该修复没有触发新的真实 freee 写入；完整 JSON 的真实确认留到下一次本来就需要创建的本人申请。
